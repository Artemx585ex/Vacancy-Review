# Автоматическое обновление отчёта

Этот проект каждый день в 09:00 по Москве скачивает свежие вакансии, собирает
отчёт и публикует его в уже созданный Cloudflare Worker `old-flower-c5e6`.

## Один раз настройте GitHub

1. Создайте новый пустой репозиторий на GitHub, например `vacancy-review`.
2. Загрузите в него **содержимое** этой папки, включая скрытую папку `.github`.
3. В Cloudflare откройте **My Profile → API Tokens → Create Token**.
4. Создайте токен с шаблоном **Edit Cloudflare Workers**. Ограничьте его своим
   аккаунтом. Сохраните созданный токен: позже Cloudflare его не покажет.
5. В Cloudflare откройте любую страницу аккаунта и скопируйте **Account ID** из
   правой боковой панели.
6. В GitHub: репозиторий → **Settings → Secrets and variables → Actions** →
   **New repository secret**. Добавьте два секрета:

   - `CLOUDFLARE_API_TOKEN` — токен из шага 4;
   - `CLOUDFLARE_ACCOUNT_ID` — Account ID из шага 5.

7. Откройте вкладку **Actions**, выберите workflow **Update vacancy report** и
   нажмите **Run workflow**, чтобы сделать первую автоматическую публикацию.

После успешного запуска сайт будет обновляться ежедневно в 09:00 МСК. Если
нужно запустить обновление вне расписания, снова используйте **Run workflow**.

## Важно

Токен и Account ID добавляются только в Secrets GitHub — не помещайте их в
файлы репозитория и не отправляйте в чат.
