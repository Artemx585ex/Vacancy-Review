# Ревью вакансий career.avito.com по гайду

Инструмент выкачивает все вакансии с карьерного сайта Авито, проверяет их по
чек-листу гайда описания вакансий (типографика, структура, дискриминация,
клише и т.д.) и собирает локальный сайт-отчёт со светофором, тирами
проблемности, графиками и выгрузкой в Excel.

Никаких нейронок и внешних сервисов: чистый Python (стандартная библиотека),
запросы идут только на career.avito.com.

## Требования

- Python 3.8 или новее (`python3 --version`)
- интернет до career.avito.com

## Запуск на Mac (без терминала)

Дважды кликните **«Запустить.command»**. При первом запуске скрипт скачает
вакансии (~1–2 минуты), проверит их и сам откроет отчёт в браузере.

Пока окно терминала открыто, в правом верхнем углу отчёта работает кнопка
**«⟳ Обновить данные»** — она перекачивает вакансии и показывает ход
обновления прямо на странице. Закроете окно — отчёт продолжит открываться
двойным кликом по `site/index.html`, просто без кнопки обновления.

### Если macOS блокирует запуск («не удаётся проверить разработчика»)

Файл приехал из интернета, поэтому macOS по умолчанию не даёт его запустить.
Разрешить нужно один раз, дальше — обычный двойной клик:

- **macOS 14 (Sonoma) и старее:** правой кнопкой по «Запустить.command» →
  «Открыть» → в окне предупреждения снова «Открыть».
- **macOS 15 (Sequoia) и новее** (правый клик там больше не помогает):
  1. дважды кликните файл и в окне блокировки нажмите «Готово» (не «В корзину»!);
  2. откройте «Системные настройки» → «Конфиденциальность и безопасность»;
  3. прокрутите вниз — там будет строка про заблокированный «Запустить.command»,
     нажмите «Открыть всё равно» и подтвердите паролем или Touch ID.
- **Запасной путь без настроек:** откройте Терминал (Cmd+Пробел → «Терминал»),
  перетащите мышкой файл «Запустить.command» прямо в окно терминала и нажмите
  Enter — запуску вручную из терминала macOS не препятствует.

Ещё macOS может спросить *«Установить инструменты командной строки?»* (если
Python ещё не ставился) — согласитесь, дождитесь установки и запустите файл
ещё раз.

## Запуск из терминала

```bash
python3 serve.py     # сайт с кнопкой «Обновить данные» на http://localhost:8765
./update.sh          # либо разово: скачать, проверить, собрать и открыть файл
```

На Linux замените `open` в update.sh на `xdg-open`; на Windows запустите
`python serve.py` — дальше всё в браузере.

## Полезное

- перекачать всё заново (тексты вакансий отредактировали):
  `python3 fetch_vacancy.py --all --force && python3 check_vacancy.py && python3 build_site.py`
- скачать одну вакансию: `python3 fetch_vacancy.py <URL вакансии>`
- вакансии, которые уже закрыли на сайте, помечаются в отчёте серым бейджем
  «не на сайте» — их можно скрыть галочкой «скрыть закрытые» или удалить
  кнопкой «🗑 Удалить закрытые» (работает, пока открыто окно терминала);
  активные вакансии кнопка не тронет

## Состав

| Файл | Что делает |
|---|---|
| `fetch_vacancy.py` | качает вакансии из sitemap сайта в markdown |
| `check_vacancy.py` | проверяет по правилам гайда → `report.json` |
| `build_site.py` | собирает самодостаточный `site/index.html` |
| `serve.py` | локальный сервер отчёта с кнопкой «Обновить данные» |
| `update.sh` | разовое обновление одной командой |

В отчёте: красный статус — точное нарушение гайда (критическая ошибка),
жёлтый — эвристика, которую стоит проверить глазами. Вакансии разбиты на три
тира по числу критических ошибок: Т1 — больше 5, Т2 — 2–5, Т3 — меньше 2
(подробности — кнопка «ⓘ Что такое тиры» на сайте). Кнопка «показать ↗» у
замечания открывает вакансию на сайте и подсвечивает проблемное место.
Дата последнего обновления данных показана в шапке отчёта.
